# Telegram Video Downloader Bot

Telegram-бот скачивает видео по ссылкам из YouTube, TikTok, Instagram, X/Twitter, Reddit и других сервисов, поддерживаемых [yt-dlp](https://github.com/yt-dlp/yt-dlp). Бот отправляет готовое видео обратно в чат, по возможности подготавливая его для воспроизведения на iPhone.

## Возможности

- скачивание видео по обычной `http`/`https`-ссылке;
- объединение видеопотока и аудио через `ffmpeg`;
- обязательная перекодировка в H.264/AAC для широкой совместимости с iPhone;
- запрос подтверждения, если у источника нет версии видео со звуком;
- сжатие роликов, превышающих лимит Telegram Bot API;
- ограничение очереди, частоты запросов и времени обработки;
- автоматическое удаление временных файлов после завершения задачи.

## Локальный запуск

Нужны Python 3.12+ и установленный `ffmpeg`, доступный в `PATH`.

```bash
git clone https://github.com/kalashdeadw8/telegram-video-bot.git
cd telegram-video-bot
python -m venv .venv
```

Активируйте виртуальное окружение и установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте файл `.env` рядом с `main.py`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

Запустите бота:

```bash
python main.py
```

Никогда не коммитьте `.env`, `tocken.env` или `cookies.txt`.

## Деплой на Railway

В репозитории есть `Dockerfile`: он устанавливает `ffmpeg` и запускает `main.py`.

1. Подключите этот GitHub-репозиторий к проекту Railway.
2. В разделе **Variables** добавьте `TELEGRAM_BOT_TOKEN`.
3. Railway автоматически соберёт Docker-образ при push в ветку `main`.

Для доступа к контенту, требующему авторизации, можно добавить переменную `COOKIES_B64`: это base64-представление файла `cookies.txt` в формате Netscape. Используйте cookies только от собственной учётной записи и храните их как секрет Railway.

## Настройки окружения

| Переменная | Значение по умолчанию | Назначение |
| --- | ---: | --- |
| `MAX_CONCURRENT_JOBS` | `2` | Одновременные скачивания/перекодирования. |
| `MAX_QUEUED_JOBS` | `10` | Максимум ожидающих ресурсоёмких задач. |
| `USER_COOLDOWN_SECONDS` | `15` | Минимальная пауза между ссылками от одного пользователя. |
| `MAX_VIDEO_DURATION_SECONDS` | `1800` | Максимальная длительность ролика в секундах; `0` отключает лимит. |
| `FFMPEG_THREADS` | `2` | Число потоков ffmpeg. |
| `TRANSCODE_TIMEOUT_SECONDS` | `300` | Таймаут основной перекодировки. |
| `COMPRESSION_TIMEOUT_SECONDS` | `300` | Таймаут одной попытки сжатия. |
| `TEMP_DIR_TTL_SECONDS` | `3600` | Время жизни временной папки после аварийного завершения. |
| `YTDLP_PROXY` | — | Необязательный proxy для yt-dlp. |

## Что изменилось в последнем обновлении

- Добавлены отдельные временные каталоги для каждой загрузки и их очистка после отправки.
- Добавлены очистка старых каталогов после перезапуска, лимит длительности видео и ограничение очереди.
- Усилена защита ссылок: отклоняются localhost, частные IP-адреса и URL с учётными данными.
- Добавлены rate limit для пользователей, сетевые таймауты yt-dlp и безопасные сообщения об ошибках.
- Подтверждение скачивания ролика без звука теперь привязано к автору запроса и сроку действия кнопки.
- Сжатие также выдаёт H.264 High@4.1, `yuv420p`, CFR и AAC, сохраняя требования совместимости с iPhone.
- Добавлены Docker-конфигурация, `.dockerignore`, тесты проверки URL и защита секретов через `.gitignore`.

## Ограничения

- Telegram Bot API ограничивает размер отправляемого ботом файла. Бот пытается сжать большой ролик, но слишком длинные видео могут всё равно не поместиться.
- Доступность источников зависит от правил самих платформ и актуальной поддержки yt-dlp.
- Скачивайте только контент, на который у вас есть права, и соблюдайте правила используемых сервисов.
